## Linux Setup
(ensure python/pip is setup correctly prior to running)

``` 
pip install -r requirements.txt
python main.py 
```

### or through venv (preferred)

``` 
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py 
```
